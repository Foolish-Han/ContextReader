# 使用与排错

## 页面不出现标记或划选入口

1. 在 `chrome://extensions` 确认加载的是当前目录里的 `dist`，并允许在所有网站访问。
2. 更新扩展后重新加载，再刷新文章。
3. 查看扩展弹窗是否停用了该网站。Chrome 内部页面、扩展页、内置 PDF、表单和编辑区不是普通阅读正文。
4. 新的表达需要先划选解释并收录。已收录表达和已解句段会自动标记；相同拼写不等于同一语境已解释。句段、任务只在原文和位置可确认时标注，原文修改或重复段落有歧义时不猜测。

## 微信读书

首次安装、更新扩展、重启浏览器或重新启用微信读书后，正文可能已在扩展确认该网站启用状态前绘制，因而尚未被捕获。扩展弹窗会提示“尚未捕获正文”。可尝试刷新阅读页；如果仍未恢复，请翻页后返回或切换章节，让阅读器在扩展就绪后重新绘制正文。刷新本身不保证捕获，恢复需要一次可读取的原生重绘。

按平常方式划选，微信读书原生菜单与语境卡片同时可用；点击原生划线或写想法时，语境卡片自动关闭，不接管笔记操作。已收录词的悬停在原生选区、菜单和编辑器关闭后恢复。

语境优先来自排版过程中的完整原文段落，能唯一定位才关联历史；取不到完整段落时仅使用当前可读片段。图片、扫描 PDF、混淆字形或无法确定边界的选区不会被猜测为正文。停用该网站会撤去语境标记与卡片，不删除微信读书的划线或笔记。

## 生成较慢、失败或内容不合适

关闭浮框后可以继续读，进度在知识库“任务”中。前面有请求时会排队。模型名称由服务决定；连接检查读取目录，不代表每个模型都能完成推理。

检查任务的具体错误和模型/连接方式。使用“重新生成”替换异常解释，或修订基础释义；失败不会清除原内容。缺失音标显示“读音待确认”，模型不确定性直接显示在本处含义中。非常规拼写、俚语和复合词需保留完整原文核对，模型生成结果不等于词典核验；再次生成不会保证字面一致，但会拒绝误换词条并保留已有音标。后台中断且结果未确认时，明确重试可能产生一次新请求，不会静默代发。

## ChatGPT 登录或模型不可用

在设置点击 `Continue with ChatGPT`，本人在打开的 OpenAI 页面完成登录和订阅授权。无需运行 CMD、PowerShell 或本机服务。正常重启浏览器、在扩展管理页重新加载或升级版本，都应复用加密保存的登录，不要求重复认证。更新请保留原安装目录与固定扩展 ID；不要先移除扩展或清理扩展数据。网络或服务临时故障会保留登录并提示重试；授权被撤销、过期或刷新结果不确定时才需要重新登录。一次性授权码不会被自动重放。换账号或旧授权失效时使用相应连接操作。无法使用订阅时可自行选择 API Key 模式，应用不会自动切换到付费 API。

浏览器内回调已通过合成服务回归；真实账号授权仍需本人验收。失败时提供去除凭据的设置页错误文字，不提供回调地址、授权码、Cookie 或 token。

## Google 没有同步

正常连接后就是自动同步；“立即同步”只提前检查一次。查看设置中的状态、上次同步和具体错误。Chrome 必须运行才能继续同步；断网保留本机改动。

如果点击连接看到“应用配置缺失”，请确认安装包与构建，而不是要求普通用户建立 Google 开发项目。更新后重新加载扩展并刷新设置。连接诊断会显示版本、扩展 ID 和公开 Client ID。

Google 控制台处于 Testing 时，其他账号可能需要发布者加入测试用户；应用发布、验证和受众配置由维护者处理，见 [Google 接入](google-sync-setup.md)。

## 备份与数据

知识库右上角可以导出/导入 JSON。备份不含密钥与 OAuth 凭据。导入会去重，不把“已收录”变成“已掌握”。

报告问题前查看 [安全政策](../SECURITY.md)，不要贴出真人凭据、知识库或私人原文。
