语境 Context Reader

隐私与数据

这份说明介绍扩展如何处理你选择阅读和保存的内容，以及可选连接服务会收到什么。

在设备上保存什么

表达、释义、语境、句段和人工修订保存在当前 Chrome 扩展的本机数据库中。任务进度、站点开关和外观设置保存在扩展本机存储中。

API Key 默认只保存在本次浏览器会话；如果你选择记住，它保存在扩展本地存储中，本扩展不再对该本地副本额外加密。ChatGPT 登录凭据保存在独立数据库中，以 AES-GCM 加密；明文只保留在扩展后台内存中。这不等同于系统钥匙串，也不能抵御已被控制的浏览器资料或可信扩展上下文。

请求解释时发送什么

你主动请求解释或重新生成时，扩展把所选内容、有限的附近原文、位置提示、页面标题和清理后的来源网址发送给你选择的模型服务。网址中不属于已知认证或跟踪参数的查询内容可能保留。新表达还可能触发一项学习资料请求。

模型服务按照其自身条款和隐私政策处理请求。匹配已有标记、悬停和阅读历史使用已保存资料，不调用模型。扩展没有单独的开发者遥测服务器。

Google Drive 同步

只有你主动连接 Google Drive 并完成授权后，知识库才会同步到你的 Google 账号中该应用专用的隐藏数据区。扩展只申请 drive.appdata 范围，不取得一般 Drive 文件浏览权限。任务、API Key、ChatGPT 凭据、站点开关和外观设置不随知识库同步。

本扩展对从 Google API 获取的信息的使用和传输遵循 Chrome Web Store 用户数据政策，包括 Limited Use 要求。扩展不出售用户数据或将其用于个性化广告，项目开发者不会通过扩展主动读取用户的私人内容。

网页权限和微信读书

扩展需要访问普通 HTTP 和 HTTPS 页面，以标记已有表达、响应选区，以及连接你配置的模型服务。你可以在扩展弹窗中关闭指定网站。扩展还使用浏览器存储、当前标签页、脚本、右键菜单、定时器和身份授权权限。

微信读书适配在阅读页面启用时临时读取页面正在排版的文字与段落，以识别选区和有限上下文；不请求整本书接口，也不持久保存未提交的章节。ChatGPT 登录回调只在对应登录标签页观察本机回环地址，不读取文章请求正文。

管理、导出与删除

你可以在知识库修订或删除条目，并导出备份；删除会在连接同步时形成删除标记。断开 Google 同步保留本机知识并停止后续同步。移除 API Key、退出 ChatGPT 与删除知识库是不同操作。

卸载扩展或删除 Chrome 个人资料会移除本机数据。卸载前请先导出备份，并确认任何需要保留的同步已完成。跨设备恢复取决于同一应用和账号；真实服务的恢复行为仍需本人验证。

问题与支持

一般问题可以通过 项目反馈页面联系维护者。公开反馈请不要包含密钥、授权信息、私人文章或知识库；涉及安全和隐私的内容可使用项目的私下报告入口。
